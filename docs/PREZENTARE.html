4. PageSpeed

Rezultatul de la https://pagespeed.web.dev pe URL-ul public: print screen 18 (Mobile) și 19 (Desktop). Optimizări aplicate: compresie gzip, cache de 1 an pe resursele cu hash și 30 de zile pe imagini, code splitting pe rute (JS încărcat la cerere), datele inițiale (sesiune, produse, facete) incluse direct în HTML (fără lanț HTML → JS → API), CSS inline (fără resurse care blochează randarea), preload + fetchpriority="high" pe primele imagini, imagini SVG ușoare cu width/height declarate, loading="lazy" sub pliu, meta description/titlu/canonical per pagină, robots.txt + sitemap.xml + llms.txt, linkuri crawlabile, JVM cu SerialGC și încălzire la pornire. Local: ./scripts/measure_speed.sh generează rapoarte Lighthouse în docs/speed-reports/.

5. Conținutul arhivei

Cod sursă (src/, frontend/), scripturi (scripts/, cu scripts/tools/ pentru print screen automat), documentație (docs/: PREZENTARE.md, DEPLOY.md, screenshots/), iar în rădăcină pom.xml, Dockerfile, docker-compose.yml, render.yaml. Fișierele generate la rulare stau în .runtime/ (ignorat de git). Rulare locală: ./scripts/run.sh (necesită JDK 17+, Maven, Node 18+, sau Docker). Print screen automat: ./scripts/screenshots.sh [URL] (generează și PREZENTARE.html). Totul dintr-o comandă (aplicație + link public + print screen-uri): ./scripts/auto.sh sau ./scripts/auto.sh multi. Documentare .docx/.pptx: ./scripts/docs.sh (se rulează automat după print screen-uri și la arhivare). Arhivarea: ./scripts/package.sh nume_prenume.
